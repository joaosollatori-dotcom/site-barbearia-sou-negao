# Barbearia Sou Negão

Site institucional da Barbearia Sou Negão — barbearia especializada em corte, barba e prótese capilar em Itabuna, BA.

## Stack

HTML, CSS e JavaScript puros — sem framework, sem build, sem dependências.

## Como visualizar

Basta abrir o `index.html` no navegador, ou subir um servidor local:

```bash
# Opção 1: Python
python3 -m http.server 3000

# Opção 2: Node (serve)
npx serve .

# Opção 3: abrir direto
# Duplo clique em index.html
```

Depois acesse `http://localhost:3000`.

## Estrutura

```
index.html      # estrutura da página + SEO (OpenGraph, JSON-LD)
styles.css      # estilos (cores, tipografia, layout, responsivo)
script.js       # interatividade (menu mobile, scroll do header, serviços, ano)
```
